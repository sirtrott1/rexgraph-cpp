# RFCXA version 1 fixtures

These six canonical archives cover a selected real cubic, three Hermitian
cyclotomic coefficient fields, a declared nonflat realization and a redundant
reconstruction with a singular represented form. Each retains its complete RFCX
source and declared stalk ranks. Typed records distinguish vectors, covectors,
maps, measurement forms and certified positive metrics.

The `algebraic_storage` example produces these bytes. Storage tests compare them
with fresh declarations and validate malformed images. The redundant archive
retains the named accession and reconstruction records satisfying `R A = I`.
Changes to these files require an intentional wire-format decision.
